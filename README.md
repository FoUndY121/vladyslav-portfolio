# Vladyslav Mashyrov — Portfolio

A responsive one-page portfolio built with React and Vite.

## 1. Add your photo

Place your original portrait in:

```text
public/profile-photo.png
```

If the file is missing, the site automatically shows the included VM placeholder.

## 2. Run locally

```bash
npm install
npm run dev
```

## 3. Build

```bash
npm run build
```

## 4. Deploy to Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the repository.
4. Keep the detected Vite settings and click **Deploy**.
